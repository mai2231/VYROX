How much is shipping?
₱99 for Metro Manila and ₱149 for provincial addresses. Standard delivery is 3–5 days. Orders of ₱2,500 or more ship free. Express adds ₱150 and arrives in 1–2 days where available.
Do you ship outside the Philippines?
Not yet. Phase 1 covers Philippine addresses only. International shipping is on the roadmap after the backend and fulfilment integrations land.
How do I track my order?
Open Track order and enter the reference from checkout. Demo references created in this browser appear in order history. Live courier scanning arrives with Phase 4 logistics.
Can I change or cancel an order?
In the demo, an admin can change fulfilment status from the console, but there is no customer self-service edit yet. Real orders will allow changes until the processing stage in Phase 3.
Which payment methods work?
The interface shows GCash, Maya, bank transfer and cash on delivery. None of them charge money in Phase 1. You can enter a fake reference and watch the order stay “Awaiting verification” until an admin approves it.
Why does my order not say paid?
Because it is not. Payment is only marked paid after manual verification in the demo admin queue. We would rather show an honest pending state than fake a successful charge.
What is the return policy?
Thirty days on unused pieces in original packaging. Beauty products must be unopened for hygiene reasons. Contact support with your reference to start a return. Demo orders have no real fulfilment.
How do I choose a size?
Product pages list available sizes and formats. Fashion pieces note their cut in the description — the boxy tee is intentionally roomy, the biker jacket is cropped. When between sizes, size up for outerwear and down for oversized knits.
Do coupons stack?
No. One code at a time. VYROX10 takes 10% off capped at ₱500. URBAN500 takes ₱500 off orders of ₱3,000 or more. FREESHIP waives shipping. Minimums are checked against the subtotal before shipping.
What is actually real on this site?
The interface, interactions, validation, cart math, filters, admin actions and animations are real front-end code. Products, orders, customers, reviews and figures are sample data. Accounts are simulated and no credentials are stored. There is no server yet.
Where is my data stored?
Cart, wishlist, theme, demo orders, addresses and admin changes use localStorage in this browser. No passwords, tokens or payment data are stored. Clear site data or use Admin → Settings → Reset demo to wipe everything.
Can I see the admin console?
Yes. It is linked in the account menu and footer. It is an unauthenticated demonstration console with sample data — every action persists locally and can be reset. It is not secured and must not be deployed as-is.
